# Worker hands

The hand and distal forearm surfaces are derived from the MakeHuman Community
base mesh. The finger rig is derived from the official default skeleton and
weights. The game texture contains only the UV regions used by the hands and
forearms. These source assets are CC0.

- Base mesh: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
- Skeleton and weights: https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data/rigs
- Skin atlas: https://download.tuxfamily.org/makehuman/assets/1.2/base/skins/textures/young_lightskinned_male_diffuse2.png
- Asset licensing: https://static.makehumancommunity.org/about/license.html

The preparation scripts live in the workspace's `tools` directory. The game
uses its own grip and pinch poses.
