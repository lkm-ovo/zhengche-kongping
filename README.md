# 整车空瓶

一款第一人称瓶子回收游戏。从手工刮标、清洗、消毒、沥干和出售开始，用回收收入升级刀具，逐步接入自动生产线。

主线从一次炒股亏损开始：接手街边回收点，用第一笔回款启动生意，最终把站里的周转金攒到 ¥12,000。故事不扣除资金，也不会挡住后续扩产。

## 运行

1. 用 Godot `4.7.2` 打开 `game/project.godot`，按 `F5` 运行项目。
2. Windows 下也可以将 `Godot_v4.7.2-stable_win64.exe` 放到 `build/engine/`，双击 `运行整车空瓶.cmd`。

- `WASD` 移动。按 `E` 打开处理室右侧滑门，走近车库来料区，对准瓶堆或来料牌按 `E` 装满，按 `Shift + E` 只拿一只，也可按 `1`–`6` 按瓶型取瓶。到脱标台再按 `E` 拿出一只处理。
- 洗净、消毒并沥干后按 `E` 把瓶子放进工作台的成品筐。对准成品筐按 `E` 搬走，出滑门右转，在收购窗口按 `E` 打开收购单。点击卸筐交货，再选收购单结款。未装满的筐也可以卖。
- 收购窗口显示实时单价、待售量和今日剩余额度。同一瓶型积压越多，报价越低。买家昨天收得越多，今天的额度扣减越多。市场随经营规模扩容，区域回收中心的买家每天可收数十万只。
- 市场每 120 秒游戏时间换日，运行加速也会缩短等待。买家收满后，货留在窗口，可以点「等到次日收购」。自动销售按实时价格和当日额度结款。
- 成品筐初始装 4 只。首笔回款后对准筐按 `F` 免费升到 8 只，经营到街区回收点和小仓库后，可分别花 ¥65 和 ¥140 升到 12 只、16 只。
- 开局背包能装 1 只散瓶。接到街区散货后按 `Tab` 打开站务终端，点「免费升级背包」，容量扩到 5 只并自动保存。接到整车货后，可在车库按 `E` 推小推车，最多运 20 只散瓶和 3 筐成品。推车时对准成品筐按 `E` 装车，按 `C` 停车会把成品筐和超出随身容量的散瓶留在车上。
- 刮标时按住右键向下拖动，按住左键转瓶。旧刀刮纸标十道、塑膜十二道，弹簧压刮刀分别需要三道、四道。每道结束后松开右键重刮。擦残胶时按住左键擦到一侧，再按提示折返。换刀后会从下一瓶开始使用新刀。
- `Tab` 打开站务，`J` 查看主线营业簿。首笔出货后开放首台设备采购，后续设备随站点扩张解锁。
- 操作台内随时按 `Esc`、`S` 或 `R` 离开，手里的瓶子收回随身储物。重新上台从最近完成的工序继续，已处理好的瓶子按 `E` 装筐。在来料区按 `R` 可放回随身的待处理瓶，走动时按 `Esc` 释放鼠标。

## 测试与导出

在仓库根目录运行下列命令（将 `godot` 换成本机 Godot 可执行文件的路径）。测试不会读取或写入游戏存档。

```sh
godot --headless --path game --editor --import
godot --headless --fixed-fps 60 --path game --script res://verify/playtest.gd -- --yard-playtest
```

如需导出 Windows 版，先在 Godot 中安装与编辑器同版本的导出模板，再使用项目内的 `Windows` 预设导出。仓库不包含 Godot 本体、导出模板、构建产物或本地存档。手部素材来源见 [素材说明](game/assets/worker_hands.SOURCE.md)。
